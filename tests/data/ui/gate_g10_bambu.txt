# Release gate G10 (QA, 2026-11-17): a Bambu Lab printer on the local network
# against the simulated one (MQTT 3.1.1 over TLS, FTPS, project_file): the
# certificate confirmed once, the state, and the print: the package arrives
# whole (its G-code byte for byte, with its MD5) and project_file starts it.
slice
wait 30
bambu sim
# Found on the network (SSDP on 1990 and 2021), as a real printer announces itself.
bambu search
expect-bambu found 01S00SIMULATED
bambu connect
bambu-wait
expect-bambu code confirm_certificate
bambu accept
bambu-wait
expect-bambu state IDLE
expect-bambu trays 4
bambu camera
expect-bambu camera 32x24
bambu camera-off
expect-bambu camera none
bambu print
bambu-wait
expect-bambu sent cube_ascii
expect-bambu whole cube_ascii
expect-bambu state PREPARE
bambu pause
bambu-wait
expect-bambu state PAUSE
bambu stop
bambu-wait
expect-bambu state FAILED
