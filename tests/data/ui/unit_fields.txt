# A length in mm or in % of the nozzle takes the unit typed with it; a bare
# number keeps the unit the field shows (the spec team's field sweep: "0,3 mm"
# was kept as 0.3 %). And the panel's limits are those of docs/CONFIG.md.
click walls.min_line_width
select-all
type 0,3 mm
key enter
expect walls.min_line_width 0.3
click walls.min_line_width
select-all
type 0,5
key enter
expect walls.min_line_width 0.5
click walls.min_line_width
select-all
type 90 %
key enter
expect walls.min_line_width 90.0%
click walls.min_line_width
select-all
type 80
key enter
expect walls.min_line_width 80.0%
click slicing.xy_offset
