# Ajustes de las fichas que el motor todavía no lee (28-10-2026)

**Qué es:** se repitió la prueba de `2026-10-26-cobertura.md` con el motor de `dev` en `32d74be`. Cada nombre de
ajuste de las fichas se le pasó al motor con un valor de prueba; si responde que no lo conoce, falta.

**Resultado:** de 479 ajustes del laminado, el motor lee 368 (77 %). El 26-10, en `dfcd143`, leía 106 de los mismos.

**Corrección:** la medición del 27-10, en `b8a12e6`, contó como leídos los 32 de `material.*`. El motor los aceptaba
con el aviso «settings group 'material' is not used yet», también con un nombre inventado. Ahora los lee: 31 de 32.

**Leído no es hecho:** que el motor lea un ajuste no dice que pase las pruebas de su ficha. Las pruebas de caja negra
(`2026-10-27-tercera-prueba.md`) siguen siendo las que dicen si coincide con Tisma Slicer.

## Cómo se repite

Un script saca de las fichas los nombres con forma `grupo.clave` y le pasa cada uno al motor con un valor de prueba
(sí, 1, 0,5, un texto, una lista) sobre un cubo de 20 mm. Cuenta como leído si lamina o si el error habla del valor y
no del nombre. Además se le pasa a cada grupo un nombre inventado: si no da error, el grupo no se cuenta.
