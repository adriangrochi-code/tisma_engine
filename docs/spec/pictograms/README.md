# Pictogramas de Tisma

Dibujos propios para el modo simple (`features/accessibility_touch.md`, reglas 18 a 24). Decisión del dueño
(29-10-2026): «dibujos propios, que sean simples y entendibles». No se usan conjuntos de terceros.

## Estilo

- Cuadro de 64 × 64, sin texto adentro; el nombre va siempre al lado, en la interfaz.
- Trazo negro (#1F1F1F) de 4, puntas y uniones redondeadas.
- Pocos colores: violeta de Tisma (#7C3AED) para lo principal, violeta claro (#EDE6FB) de relleno, verde (#2E9E5B) para
  sí y listo, rojo (#D64545) para no y calor, amarillo (#F2B705) para cuidado y lo lindo. Nunca el color solo: la forma
  dice lo mismo (`accessibility_touch.md`, regla 1).
- Una sola idea por dibujo, vista de frente o de costado, sin perspectiva difícil, sin sombras ni degradés.
- La misma cosa siempre con el mismo dibujo.
- Se miran a 32 px y a 128 px antes de aceptarlos; se prueban con personas (regla 24).
