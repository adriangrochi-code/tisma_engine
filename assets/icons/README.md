# Interface icons of the engine

The plate tools' icons (`tool_*.svg`) and the settings panel's section icons (`section_*.svg`, 2026-10-26), drawn for the engine (own design, 2026-10-25) in the style of the Tisma icons
of `assets/brand/icons/`: 24×24, one gray (`#808080`) that the interface recolors, round strokes of 2 units.

| Icon | Use |
|---|---|
| `tool_add` | Add a model to the plate |
| `tool_remove` | Remove the chosen model |
| `tool_duplicate` | Duplicate the chosen model |
| `tool_move` | Move |
| `tool_rotate` | Rotate |
| `tool_scale` | Scale |
| `tool_lay_flat` | Lay on a face |
| `tool_arrange` | Arrange the plate |
| `tool_paint` | Paint (supports, seam), still to come |
| `tool_cut` | Cut with a horizontal plane (a box and a dashed line across it, 2026-10-27) |
| `tool_material` | The object's extruder and mixed colours (two circles, 2026-10-27) |
| `section_quality` | Settings panel, section Quality (thin layers) |
| `section_strength` | Section Strength (a shield) |
| `section_speed` | Section Speed (a gauge) |
| `section_support` | Section Supports (a part on pillars) |
| `section_adhesion` | Section Adhesion (a part on a brim) |
| `section_other` | Section Others (sliders) |
| `section_temperature` | Material, Temperatures (a thermometer) |
| `section_cooling` | Material, Cooling (a fan) |
| `section_flow` | Material, Flow (a drop) |
| `section_retraction` | Material, Retraction (an arrow back up) |
| `section_needs` | Material, Requirements (a tag) |
| `section_machine` | Printer, Machine (a frame and its bed) |
| `section_nozzle` | Printer, Nozzle and extruder |
| `section_limits` | Printer, Limits (a gauge at its end) |
| `section_gcode` | Printer, G-code (code brackets) |
| `help` | The help panel (a question mark in a circle, 2026-10-27) |
